This cookbook demonstrates the manual `RouteObject[]` routing approach supported by
`@equinor/fusion-framework-react-router`. Use it when maintaining applications that have not
migrated to the route DSL. It includes examples of `errorElement`, React Router v7
`ErrorBoundary`, nested routes, and loader errors.
